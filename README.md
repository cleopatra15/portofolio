## 🚀 Featured Projects

### 1. [OOP Bookstore Management System](./OOP)
A robust CRUD application designed to manage a bookstore's inventory and operations, built with advanced Object-Oriented Programming principles.
* **Tech Stack:** C++ (STL)
* **Key Features:** Beyond standard CRUD operations, the system includes dynamic discount applications, customer loyalty verification, and delivery time estimations.
* **Technical Highlights:** Implemented polymorphism, inheritance, custom exception handling, class and function templates, and STL algorithms. Structured using **Singleton** and **Abstract Factory** design patterns.

### 2. [Digital Magazine Subscription Database](./'DataBases - Magazine Platform')
A comprehensive relational database system developed for a digital magazine platform to manage subscriptions, sales, and analytics.
* **Tech Stack:** Oracle SQL
* **Key Features:** Manages publications and clients, handles subscription activations, automated invoice generation, review collections, and sales statistical analysis.
* **Technical Highlights:** Designed via Entity-Relationship modeling and normalized up to 5NF (with justified denormalization). Features complex queries (WITH clauses, outer joins, synchronized subqueries), execution plan optimization using indexes, and concurrent transaction isolation mechanisms.

### 3. [Formal Languages & Automata Simulators](./Automata-Simulators)
A collection of simulators mapping theoretical automata theory to executable code.
* **Tech Stack:** Python, C++
* **Key Features:** Simulators for Deterministic Finite Automata (DFA) and Non-Deterministic Finite Automata (NFA), implemented in both Python and C++ to contrast language paradigms.
* **Technical Highlights:** Includes a Pushdown Automaton (PDA) simulator that was practically applied to create the logic for a terminal-based mini-game.

### 4. [Interactive Candle Shop Website](./Web-Candle-Shop)
A frontend e-commerce platform designed for a fictional candle business.
* **Tech Stack:** HTML5, CSS3, Vanilla JavaScript
* **Key Features:** A fully interactive, multi-page frontend website showcasing UI/UX principles, dynamic content rendering, and responsive design.

### 5. [SLCheck - Symlink Integrity Validator](./Bash-SLCheck)
A custom system utility conceived to validate file system integrity by detecting broken symbolic links within complex directory hierarchies.
* **Tech Stack:** Bash (Shell Scripting), Linux
* **Key Features:** Recursively parses file trees with advanced CLI controls (e.g., a `--follow-symlinks` flag) to dynamically allow or block symlink dereferencing.
* **Technical Highlights:** Features a native Depth-First Search (DFS) algorithm built entirely in Bash (avoiding external utilities like `find`). Includes robust argument parsing and testing via volatile `tmpfs` environments.
